# 📊 Analyse du Comportement des Clients

## 🧠 Objectif
Ce projet vise à analyser les habitudes d'achat des clients d'une plateforme de e-commerce, en identifiant :
- Les jours les plus rentables
- Les produits et clients les plus importants
- L’évolution des ventes au fil du temps

## 📁 Contenu
- `customer_analysis.py` : script principal d'analyse
- `data/purchase_behavior.csv` : jeu de données
- `figures/` : graphiques générés automatiquement

## 🔧 Librairies utilisées
- pandas
- matplotlib

## 📈 Visualisations incluses
- Histogramme des paniers
- Top produits
- Ventes par jour de la semaine
- Top clients
- Ventes dans le temps
